CHEGADA MANUAL DE FACÇÃO

Esta versão adiciona, na aba Facções, o botão Chegada manual.

Use quando uma remessa chegou, mas esqueceram de lançar o envio/chegada antes.
O lançamento pede: OP, REF, cor, quantidade, o que foi feito/processo, quem fez/facção, data de chegada e observação.

Segurança:
- Não apaga dados.
- Não limpa OPs.
- Não mexe no login.
- Não reimporta a planilha.
- Cria uma movimentação de facção com origem manual.
- Se existir preço por REF + PROCESSO, gera pagamento.
- Se não existir preço, deixa pagamento pendente para adicionar valor.
