Correção - Necessidade com filtro de urgente e ordenação

O que entrou:
1. A Necessidade continua editável no Manejo.
2. O filtro de Necessidade agora tem opções fixas:
   - URGENTE
   - Sem necessidade
3. Ao filtrar por URGENTE, o sistema busca qualquer necessidade que contenha urgente.
4. Foi adicionado o campo Ordenar no topo do Manejo.
5. Opções de ordenação:
   - Padrão
   - Urgente primeiro
   - Necessidade: data decrescente
   - Necessidade: data crescente
   - OP decrescente
   - OP crescente
   - QTI maior primeiro
   - QTI menor primeiro
6. Não apaga e não altera automaticamente dados já lançados.

Observação:
A ordenação por necessidade usa a primeira data encontrada no campo Necessidade. Se estiver escrito URGENTE, a opção Urgente primeiro joga essas OPs para o topo.
