Correção aplicada

1. Facções são exibidas sem duplicar nomes.
2. Botão Organizar duplicadas marca cadastros repetidos como duplicados/inativos e mantém um cadastro principal ativo.
3. Envio para facção agora pergunta primeiro o processo e só depois mostra as facções permitidas para aquele processo.
4. Processos padrão: ENCAPAR BOJO, ALÇA, CALCINHA MONTAGEM, CALCINHA COMPLETA, SUTIÃ MONTAGEM e SUTIÃ COMPLETO.
5. A correção não apaga movimentações e não limpa dados lançados pelos usuários.
