VERSÃO SEGURA PARA GITHUB

Esta versão não contém dados reais da planilha da Lígia.
Suba estes arquivos no GitHub normalmente.

Para migrar/testar:
1. Acesse o site como admin.
2. Vá em Importar / Backup.
3. Em Migração Lígia, clique em Selecionar JSON da Lígia.
4. Escolha o arquivo dados-ligia-migracao-final-segunda.json no seu computador.
5. Clique em Ver resumo dos dados.
6. Clique em Importar dados da Lígia.

Não suba no GitHub os arquivos:
- dados-ligia-migracao-final-segunda.json
- migracao-ligia-final-segunda.zip
- Planilha Lígia (1).xlsx
- resumo_migracao_ligia_final_segunda.xlsx
