Agora, ao buscar uma OP no Rastreamento, o sistema mostra a linha principal e abaixo uma trilha com:
- data de tecido, quando existir;
- facção inicial da planilha da Lígia;
- processo inicial inferido, principalmente ENCAPAR BOJO;
- chegada da facção;
- envio para produção/célula quando FASE=PRODUÇÃO;
- movimentações reais criadas no sistema;
- correção manual de local, quando existir;
- local atual.
