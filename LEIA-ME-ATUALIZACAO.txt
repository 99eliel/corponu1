ARQUIVOS PARA SUBSTITUIR NA RAIZ DO GITHUB
1. update.js
2. sw.js
3. version.json
4. firebase-rules.txt

O arquivo firestore-rules.txt possui o mesmo conteúdo de firebase-rules.txt e foi incluído para facilitar copiar e colar no Firebase.

PASSO OBRIGATÓRIO NO FIREBASE
1. Abra Firebase Console.
2. Entre em Firestore Database > Rules.
3. Copie todo o conteúdo de firebase-rules.txt ou firestore-rules.txt.
4. Substitua as regras atuais.
5. Clique em Publicar.

Sem publicar as regras novas, o usuário comum poderá ver o botão, mas não conseguirá consultar/corrigir/excluir o pagamento criado por ele.

NOVO BOTÃO
Facções > Movimentações registradas

FUNCIONAMENTO
- Cada usuário vê somente as chegadas registradas pelo próprio usuário.
- A lista mostra OP, referência, facção, processo, quantidade recebida, data e pagamento.
- Editar uma chegada recalcula automaticamente o pagamento pendente.
- Em chegada normal, OP, referência, processo e facção ficam protegidos. O usuário corrige data, quantidade recebida, desconto e observação.
- Em chegada manual, o usuário também pode corrigir OP, referência, cor, processo, facção e data de envio.
- Se não existir preço para referência + processo, o pagamento fica como pendente de valor.
- Se o pagamento já estiver marcado como pago, editar/excluir fica bloqueado e exige o administrador.
- Etapas já encaminhadas ficam bloqueadas para o usuário, evitando quebrar o rastreamento.
- Movimentações já bipadas ainda podem ter a chegada editada, mas não podem ser excluídas pelo usuário.

EXCLUSÃO / DESFAZER
- Chegada normal: remove a chegada, apaga o pagamento pendente e devolve a remessa para o status Em facção.
- Chegada manual: cancela o registro, remove o pagamento pendente e preserva o histórico para auditoria.

TESTE RECOMENDADO
1. Entre com um usuário comum.
2. Registre a chegada de uma movimentação de facção.
3. Abra Movimentações registradas.
4. Edite quantidade ou data e salve.
5. Confira o valor na aba Pagamentos com o administrador.
6. Faça outro teste usando Desfazer chegada.
7. Confirme que a remessa voltou para Em facção e o pagamento pendente desapareceu.
