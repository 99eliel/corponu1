COMO PUBLICAR
1. Abra o repositório do sistema no GitHub.
2. Substitua update.js, sw.js e version.json pelos arquivos desta pasta.
3. Faça o commit dos três arquivos juntos.
4. Abra o sistema e pressione Ctrl + F5 uma vez.
5. Entre na aba Manejo/Necessidade.

COMO A CORREÇÃO FUNCIONA
- Quando uma OP aparece com Necessidade vazia, o sistema procura o valor nos dados originais da Lígia.
- O valor recuperado aparece destacado em amarelo para conferência.
- Informações que já estiverem preenchidas não são substituídas.
- A correção também protege o botão verde da linha para não salvar vazio quando existe valor original.

RESTAURAÇÃO DEFINITIVA
Na aba Manejo aparecerá o botão:
"Restaurar necessidades vazias"

Ao clicar:
1. O sistema confere todas as OPs do Firebase.
2. Mostra quantas estão vazias e possuem valor original disponível.
3. Pede confirmação antes de gravar.
4. Preenche somente os campos vazios.
5. Preserva todas as Necessidades que já estejam preenchidas.

IMPORTANTE
- Execute o botão de restauração com uma conta administradora.
- Clique apenas uma vez e aguarde a mensagem de conclusão.
- Nenhuma OP preenchida manualmente será sobrescrita.
- Se o botão não aparecer imediatamente, navegue para outra aba e volte para Manejo, ou use Ctrl + F5.
