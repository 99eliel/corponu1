CORPONU — LIBERAR EDIÇÃO DE LOCAL PARA USUÁRIOS COMUNS

VERSÃO
2026-07-28-edicao-local-usuarios-1

ARQUIVOS PARA SUBSTITUIR NA RAIZ DO GITHUB
- update.js
- sw.js
- version.json
- firebase-rules.txt

ARQUIVO ALTERNATIVO DAS REGRAS
- firestore-rules.txt possui exatamente o mesmo conteúdo de firebase-rules.txt.
- Use somente um deles para copiar e colar no Firebase.

PASSO OBRIGATÓRIO NO FIREBASE
1. Abra Firebase Console.
2. Entre em Firestore Database > Rules.
3. Apague as regras antigas.
4. Cole todo o conteúdo de firebase-rules.txt.
5. Clique em Publicar.

FUNCIONAMENTO
- O botão Mover / editar local continua na linha da aba Manejo.
- Usuário comum ativo agora consegue salvar a correção.
- O motivo continua obrigatório.
- A OP recebe o local, destino, processo e datas corrigidos.
- Se o novo local for facção ou célula, é criada a movimentação correspondente.
- A ação fica registrada em ajustesMigracao e logsAlteracoes com UID, nome e data.
- O administrador continua usando a rotina original do sistema.

SEGURANÇA
- Usuário comum só pode criar e ler o próprio registro de ajuste.
- Somente o administrador pode alterar ou excluir registros de ajuste.
- Exclusão de OP, cadastros gerais, valores e configurações continuam restritos.

TESTE RECOMENDADO
1. Faça login com usuário comum.
2. Abra Manejo.
3. No menu de uma OP, clique em Mover / editar local.
4. Altere local/destino e informe o motivo.
5. Salve e confira se a linha atualizou.
6. Faça login como administrador e confira o histórico/log.

ATUALIZAÇÃO DO CACHE
Depois do commit e da publicação das regras, abra o sistema e pressione Ctrl + F5 uma vez se a nova versão não carregar automaticamente.
