Correção: Necessidade editável no Manejo
Versão: 2026-07-27-necessidade-manejo-editavel-2

O que foi corrigido:

1. A coluna NECESSIDADE no Manejo agora é editável.
2. Para alterar, digite o texto na própria linha e clique no botão verde ✓.
3. O sistema não usa mais a data de criação da OP como necessidade.
4. Se a OP veio da planilha da Lígia, o sistema procura a necessidade original da planilha antes de mostrar campos antigos.
5. Ao salvar, o texto digitado vira a necessidade oficial da OP.
6. O campo aceita texto livre, por exemplo: URGENTE, 02/08 A 08/08, PEGAR PRIMEIRO, ENTREGAR SEXTA.
7. A correção não apaga, não limpa e não sobrescreve dados já lançados automaticamente.
8. Só muda a OP quando o usuário editar a linha e clicar no botão verde ✓.

Como testar:

1. Abrir Manejo.
2. Escolher uma OP.
3. Alterar a coluna NECESSIDADE.
4. Clicar no botão verde ✓.
5. Atualizar a tela e conferir se o texto permaneceu salvo.

Atenção:

Esta versão mantém o modo produção seguro. Não use versões antigas com “limpa anterior”.
