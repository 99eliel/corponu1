Melhoria aplicada: gerenciamento de facções e gerenciamento de valores agora abrem em tela cheia.

Objetivo:
- Evitar que o usuário precise descer muito a tela principal.
- Separar a área operacional da área administrativa.
- Facilitar uso em telas pequenas.

Como funciona:
- Em Facções, clique em Abrir gerenciamento.
- A tela de cadastro/lista de facções abre ocupando a tela toda.
- Use Voltar para facções para retornar à tela operacional.
- Em Pagamentos, clique em Abrir gerenciamento.
- A tela de valores abre ocupando a tela toda.
- Use Voltar para pagamentos para retornar ao relatório de pagamentos.
