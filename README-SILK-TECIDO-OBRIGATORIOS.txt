Correção — SILK e DATA TECIDO obrigatórios para seguir

Alterações aplicadas:
1. O filtro SILK agora tem as opções fixas Preenchido e Sem silk, igual ao DATA TECIDO.
2. Preenchido no SILK mostra todas as OPs com nome ou data do silk preenchidos.
3. Sem silk mostra OPs sem nenhuma informação de silk.
4. Para enviar OP do Manejo para facção ou célula, o sistema exige SILK e DATA TECIDO preenchidos.
5. Se tentar seguir sem os campos, o sistema bloqueia e mostra aviso.
6. Ao confirmar envio, os campos SILK e DATA TECIDO da linha são salvos automaticamente no manejo antes de criar a movimentação.
7. Não limpa, não sobrescreve e não apaga dados lançados pelos usuários.
