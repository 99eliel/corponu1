Sistema OP Confecção - Necessidade editável

Alterações desta versão:
1. Campo Necessidade na tela Adicionar OP ficou livre, igual à planilha.
2. É possível digitar URGENTE, PRIORIDADE, uma data, um intervalo ou qualquer texto.
3. A edição de uma OP existente permite trocar a necessidade sem alterar automaticamente os outros dados do sistema.
4. Nenhum dado já lançado é apagado, migrado ou sobrescrito por esta atualização.
5. A listagem de OPs agora mostra a necessidade exatamente como está salva.
6. O filtro de necessidade do Manejo continua usando o texto salvo.
