Correção do Manejo - menu completo e processos de sutiã
Versão: 2026-07-27-menu-manejo-processos-sutia-1

Correções aplicadas:
1. O botão ⋮ do Manejo agora usa um menu flutuante único, sempre acima do botão.
2. O menu mostra novamente todas as ações: enviar para facção, enviar para célula, mover/editar local, rastreamento e limpar manejo quando permitido.
3. Na opção Enviar para facção, o sistema pergunta primeiro o processo.
4. No Manejo Sutiã, aparecem somente os processos: ENCAPAR BOJO, SUTIÃ COMPLETO, SUTIÃ MONTAGEM e ALÇA.
5. Depois do processo, aparecem somente as facções ligadas ao processo escolhido, sem duplicar nomes.
6. Nenhum dado existente é apagado ou sobrescrito.
