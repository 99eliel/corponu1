Ajuste de facções - divisão oficial

Esta versão usa somente as facções oficiais informadas pelo Eliel, divididas por processo:
- Bojo / Encapar bojo
- Alça
- Sutiã montagem
- Sutiã completo
- Calcinha montagem
- Calcinha completa

No envio para facção:
1. O usuário escolhe primeiro o processo.
2. O sistema filtra e mostra somente as facções permitidas para aquele processo.
3. Se a facção não pertencer ao processo, o envio é bloqueado.

Sutiã completo fica marcado como valor manual no fechamento.
